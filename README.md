# Aviso de Radares: páginas públicas

Política de privacidad, ayuda y contacto de la app «Aviso de Radares» para iPhone y CarPlay, publicadas con GitHub Pages:

- https://ndnoldi-sketch.github.io/radares-legal/privacidad.html
- https://ndnoldi-sketch.github.io/radares-legal/soporte.html

`servicios.json` tiene las direcciones de los servicios gratuitos que usa la app (rutas, búsqueda, tiempo y Wikipedia). La app lo lee al abrirse: si un servicio pide que dejemos de usarlo, se cambia aquí, sin actualizar la app.
